# 🌿 Génesis Psicología

### Psicoterapia centrada en la persona, con enfoque humano y cercano.

Landing page profesional diseñada y desarrollada para una psicóloga, enfocada en transmitir confianza, bienestar y cercanía mediante una experiencia visual elegante, minimalista y totalmente responsive.

---

## ✨ Vista General

Génesis Psicología es una landing page creada para presentar servicios de atención psicológica, talleres y canales de contacto en una interfaz moderna y accesible.

El diseño busca generar una experiencia cálida y profesional, utilizando una identidad visual inspirada en la naturaleza, la calma y el bienestar emocional.

---

## 🎯 Objetivos del Proyecto

* Presentar los servicios psicológicos de forma clara y profesional.
* Facilitar la reserva de sesiones mediante plataformas externas.
* Promocionar talleres y actividades de desarrollo personal.
* Generar confianza a través de una experiencia visual coherente y acogedora.
* Adaptarse correctamente a dispositivos móviles, tablets y escritorio.

---

## 🚀 Funcionalidades

## 💻 Instalación

Clonar repositorio:

```bash
git clone https://github.com/MacarenaAPR/Landing-page-Genesis-Psicologia.git
```

Ingresar al proyecto:

```bash
cd Landing-page-Genesis-Psicologia
```

Instalar dependencias:

```bash
npm install
```

Iniciar entorno de desarrollo:

```bash
npm run dev
```
